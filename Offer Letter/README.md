## 🔐 Areas of Learning

During the internship, I will work on cybersecurity concepts and practical assignments involving:

### 1. Cybersecurity Fundamentals
Understanding cybersecurity principles, the CIA Triad, hacker types, malware, phishing, ransomware, and common security threats.

### 2. Virtual Lab Setup
Building a controlled cybersecurity environment using virtualization and Kali Linux for safe security practice.

### 3. Networking & Reconnaissance
Learning IP addresses, DNS, ports, protocols, and performing authorized reconnaissance using cybersecurity tools.

### 4. Penetration Testing
Understanding the penetration-testing methodology through reconnaissance, scanning, vulnerability identification, and controlled exploitation in a safe lab.

### 5. OSINT Investigation
Collecting and analyzing publicly available information to understand digital footprints and document investigation findings.
