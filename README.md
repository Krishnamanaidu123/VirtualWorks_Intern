## 📋 Overview

This repository contains the complete set of tasks completed as part of a **Cybersecurity Internship Program**. The tasks cover foundational concepts, practical lab setup, networking and reconnaissance, penetration testing simulation, and open-source intelligence (OSINT) investigation.

The purpose of this portfolio is to demonstrate a solid understanding of essential cybersecurity principles and hands-on skills required for entry-level security roles.

## 🛠️ Technologies & Tools Used

### Virtualization & Operating Systems
- VirtualBox / VMware Workstation
- Kali Linux (Debian-based)
- Metasploitable 2 / 3 (vulnerable targets)
- OWASP Juice Shop, DVWA (web app targets)

### Command-Line & Network Tools
- **Nmap** – Network scanning and service enumeration
- **Netcat** – Networking utility for reading/writing connections
- **Dig / nslookup / whois** – DNS and domain info
- **Ping / traceroute** – Connectivity and path tracing
- **ip / ifconfig / route** – Network configuration

### Security & Penetration Tools
- **Metasploit Framework** – Exploitation and payload delivery
- **Nikto** – Web server vulnerability scanner
- **Searchsploit** – Offline exploit database search
- **Nmap NSE Scripts** – Advanced vulnerability detection
- **Burp Suite** – Web application security testing (optional)

### OSINT Tools
- **theHarvester** – Email and subdomain harvesting
- **Amass** – Subdomain enumeration
- **Shodan** – Internet-connected device search
- **Recon-ng** – Modular OSINT framework
- **Sherlock** – Username search across social media
- **Google Dorks** – Advanced search operators

### Documentation & Reporting
- Markdown (GitHub READMEs)
- Screenshots and logs for evidence
- Risk assessment matrices
- Remediation recommendations

## 🚀 Getting Started

All tasks were performed in a **virtualized environment** for safety and isolation. To replicate these exercises, follow these general steps:

1. **Install a hypervisor** (VirtualBox or VMware) on your host machine.
2. **Download Kali Linux** ISO and create a VM (see Task 2 for details).
3. **Download a vulnerable target VM** (e.g., Metasploitable 2) and set it up on the same isolated network.
4. **Configure networking** (Host-Only or NAT Network) so Kali can communicate with the target.
5. **Complete each task** sequentially, following the detailed README in each folder.
6. **Capture evidence** (screenshots, logs) as specified in each task.

> ⚠️ **Important:** Only perform scans and attacks on systems you own or have explicit written authorization to test. The vulnerable targets used here are designed for educational purposes and should never be exposed to the public internet.
